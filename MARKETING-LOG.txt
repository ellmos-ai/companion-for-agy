1. REPOSITORY AUDIT & DISCOVERABILITY BASELINE
================================================================================
- Organization: ellmos-ai & dev-bricks
- Umbrella Ecosystem: open-bricks
- Primary Category: AI Agent Infrastructure / Virtual Terminal Subprocess Connectors
- Core Positioning: Unofficial Node.js PTY-based wrapper for agy (Antigravity CLI / Gemini CLI) that captures terminal-buffer responses as clean stdout for multi-agent automation, CI/CD pipelines, and local agent frameworks.
- Distinct Value Proposition: Resolves the upstream agy architectural constraint where print-mode output is rendered to the raw virtual terminal buffer rather than piped stdout. By spawning agy within an isolated PTY (ConPTY on Windows, forkpty on macOS/Linux) and applying high-precision ANSI truecolor SGR stream filters (targeting RGB 232,234,237), companion-for-agy extracts only the pure LLM response text while eliminating UI noise, banners, and spinner frames. Provides model/effort auto-negotiation, offline preflight diagnostics (--doctor, --platform-smoke), dual return paths (stdout vs. --add-dir filesystem for CJK/bulky data), and deterministic process tree termination.
- Sibling Ecosystem Integration: Interoperates directly with dev-bricks developer tooling (safe-start-for-codex, automizer-for-claude-desktop, DevCenter, CodeBox, CareCenter-for-Codex, automation-master), ellmos-ai infrastructure (ellmos-filecommander-mcp, ellmos-codecommander-mcp, ellmos-controlcenter-mcp, ellmos-clatcher-mcp, n8n-manager-mcp, skills, sqlite-transit-sync, workflowhooker), and the open-bricks umbrella.

2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. Autonomous AI Coding Agent Developers & Swarm Operators (Claude Code, Codex, Antigravity, Kimi, n8n)
   - Needs: Programmatically invoke Gemini/Antigravity CLI models from parent agent sessions (e.g. Claude delegating tasks to Gemini) and receive clean, parseable JSON or text output without interactive prompt hangs.
   - Pain Points: Upstream agy writes responses to the terminal buffer via ncurses/TUI escape sequences; standard child_process.spawn() or shell pipes return empty stdout or corrupted control characters.
   - Companion Solution: Headless execution via isolated virtual terminal (node-pty), automated detection of trust prompts and login banners, truecolor response extraction, and structured JSON output (--json) with stream chunk events.

2. Windows & Multi-OS Antigravity / Gemini CLI Power Users & Prompt Engineers
   - Needs: Automate batch prompt execution, local LLM evaluation scripts, and cross-model benchmarks without opening interactive GUI or terminal windows.
   - Pain Points: agy CLI version changes occasionally alter reasoning effort flags or model catalog syntax, causing automation scripts to crash silently.
   - Companion Solution: Dynamic model and effort negotiation with 24-hour catalog cache, automatic fallback when effort flags must be added or removed, and cross-platform terminal compatibility (Windows ConPTY, macOS/Linux forkpty).

3. DevOps & CI/CD Pipeline Automation Engineers
   - Needs: Integrate local Gemini evaluations, automated pull request reviews, and code refactoring checks into automated build workflows without fragile environment dependencies.
   - Pain Points: Native PTY compilation issues on diverse OS runners, POSIX spawn-helper executable bit mismatches, and unhandled child process leaks stalling CI jobs.
   - Companion Solution: Comprehensive preflight diagnostic suite (--doctor, --platform-smoke, --pty-smoke), fail-closed reporting with --report-file, and cascading SIGINT/SIGTERM handlers that guarantee zero zombie processes.

4. Enterprise Security, Privacy & Compliance Auditors
   - Needs: Guarantee that local developer CLI tools operate strictly offline, without unsolicited network egress, and adhere to permissive open-source licensing standards.
   - Pain Points: Opaque wrapper tools that phone home, transmit telemetry, run with elevated administrative privileges, or bundle restrictive AGPL dependencies.
   - Companion Solution: 100% Local-First & Zero-Egress (INV-LOCAL-01), unprivileged user-mode execution (RunAsInvoker / INV-PRIV-02), verified 100% permissive open-source dependency tree (THIRD_PARTY_LICENSES.md), and formal 48h security response SLA with 5-day triage commitment (INV-SLA-10).

================================================================================
- INV-LOCAL-01: 100% Local-First & Zero-Egress (all sockets and wrappers local; zero telemetry or analytics).
- INV-PRIV-02: Non-Elevation / RunAsInvoker (runs strictly in unprivileged user mode without UAC elevation).
- INV-PTY-03: PTY Process Isolation (isolated subprocess spawning via node-pty ConPTY/forkpty).
- INV-SAN-04: Input Sanitization (sanitizeForPty strips control codes and malicious ANSI injection).
- INV-TEMP-05: Deterministic Temp Workspace Cleanup (staging directories auto-purged on exit).
- INV-PERM-06: Native Permission Pass-Through (--sandbox and --skip-permissions passed without emulation).
- INV-ANSI-07: ANSI Truecolor Stream Extraction (high-precision RGB(232,234,237) SGR filter with color probe cache).
- INV-PROC-08: Graceful Process Tree Termination (anti-zombie cascading signal handlers for node.exe and agy).
